1. As-Is → To-Be

As-Is (지금)

  • 시험 장비 화면의 값(V, ΔP, 시간)을 보고 계산기로 수기 계산
  • 결과를 종이에 기록
  • bar·psi·kPa 단위 환산과 대기압 단위 맞추기에서 실수 발생
  • 계산 오타가 나서 매번 검산이 필요함
  • 종이 기록이라 지난 결과를 찾기 어려움

To-Be (목표)

  • PC·태블릿·휴대폰 브라우저에서 값을 입력하면 단위 환산과 계산을 자동으로 처리
  • 결과는 mL/min을 크게, mL/hr를 보조로 표시하고 온도 보정은 켜고 끌 수 있음
  • 현장에서 통신이 끊겨도 기기에 저장하고, 연결되면 Google Sheets로 자동 동기화
  • 최근 입력값 불러오기와 기본값 되돌리기로 입력을 줄임
  • PASS/FAIL 판정은 계속 사람이 함 (앱은 값만 표시)

규모·기대효과 팀 2~5명 · 하루 10건 미만 · 계산·환산 실수와 검산 시간이 없어지고, 이력이 Google Sheets 한곳에 모임

2. 원천 데이터 이미 있는 자료

자료출처형태발생가져오는 방식
시험 측정값 (용기 체적 V, ΔP, 시험 압력[게이지압], 안정화 시간, 측정 시간)시험 장비 화면 (V도 장비가 측정해 표시)숫자 표시값상시 (시험마다)수기 입력 (시험자)
습윤 용액 목록사내 기준목록가끔 변경설정 화면에 수기 등록 (시험자)
계산 기본값 (대기압 1.01325 bar / 14.696 psi, 시험 온도 20 °C, 기준 온도 20 °C)과제 요청서숫자1회성앱에 기본값으로 내장, 설정에서 변경 가능

확정 계산식: Diffusion Rate [mL/min] = ΔP × V / (P_atm × t) · 온도 보정을 켜면 × T_ref[K] / T_test[K] · mL/hr = mL/min × 60 · ΔP와 P_atm은 같은 단위로 자동 환산 · 안정화 시간은 기록만 하고 계산에는 쓰지 않음

프론트엔드

필요

시험자 화면: 설정(F1), 입력(F2), 결과(F4), 최근 기록(F6) · 계산 모듈(F3)은 브라우저 안에서 실행 · React + Vite + Tailwind + vite-plugin-pwa

백엔드

간이 필요

Google Apps Script 웹앱 1개: 기록 추가·수정·삭제 받기(F5) · 별도 서버 없음

DB

필요

기기 안 IndexedDB(Dexie): 시험 기록(D3·D4), 동기화 대기열(D5), 기기 설정(D2), 용액 목록(D1) · Google Sheets(메인): 시험 기록(D3·D4) · 파일 저장소 없음

사용자·권한

사용자 유형 1개(시험자, 팀 2~5명) · 로그인·역할 구분 없음 · 사용자 명단 관리 불필요 · 시험자 이름은 기록하지 않음

연동

Google Sheets (개인 Google 계정, 저장 허용 확인됨) ← Apps Script 웹앱 API · 장비 자동 연동 없음 · 메일·그룹웨어·ERP 연동 없음

7. 미확정 사항 개발 전 결정 필요

  • 잠금 없음의 위험 수용: 앱 주소가 외부에 알려지면 누구나 Sheets에 기록을 쓰거나 수정·삭제할 수 있음 · 그대로 둠 vs 팀 접속 코드 추가(개발 부담 작음) — 확인: 팀장 · 정보보안 담당
  • 개인 기기 사용: 개인 태블릿·휴대폰에 시험 기록이 남음 · 허용 vs 회사 기기로 한정 — 확인: 정보보안 담당
  • 수정·삭제를 Sheets에 반영하는 방식: 행을 덮어쓰고 실제로 삭제 vs 수정 이력을 남기고 삭제 표시만(기록 보존) — 확인: 품질 담당 (기록 무결성 규정)
  • 습윤 용액 목록 공유: 기기마다 따로 등록 vs Sheets의 '설정' 시트에서 팀 전체 공유 — 확인: 팀 내부
  • 결과 표시 자릿수: 소수점 둘째 자리 vs 유효숫자 3자리 vs SOP 기준 — 확인: 사내 SOP
  • 부서·담당자 정보: 문서 헤더 기재용 — 확인: 요청자

범위 제외: PASS/FAIL 자동 판정 · 모델명·Lot No.·S/N·시험자 기록 · 앱 안의 이력 검색·추세 차트·엑셀 내보내기(Google Sheets에서 처리) · 승인 단계 · 로그인·권한 · AI 기능 · 시험 장비 자동 연동
